# Бюро расследований систем

Интерактивный тренажёр нотаций для системных аналитиков: **ERD, BPMN, UML, DFD**.
22 «дела» (модуля), 233 задачи, конструкторы схем и песочница модели данных.

## Что внутри

| | |
|---|---|
| Модулей | 22 |
| Задач | 233 |
| Конструкторов схем | 20 кейсов (BPMN, активности, use case, sequence, DFD, компоненты, развёртывание, состояния) |
| Песочница ERD | 3 кейса со сборкой схемы и кодом для dbdiagram.io |
| Интерактивных виджетов | 5 (кардинальность, анатомия класса, типы сообщений, статусная модель, интерфейсы) |
| Визуальных легенд фигур | 12 легенд, 79 кликабельных фигур |

### Программа

1. Словарь: что есть что
2. Типы нотаций и уровни абстракции (C4)
3. ERD: сущности и связи
4. Кардинальность и отношения
5. Песочница ERD: собери схему
6. Нормализация данных: 1НФ–3НФ
7. BPMN: пулы, дорожки, задачи
8. BPMN: события и шлюзы
9. BPMN: потоки, артефакты и данные
10. Конструктор: собери BPMN
11. UML: варианты использования
12. UML: диаграмма активностей
13. UML: диаграмма последовательности
14. Конструктор: собери UML
15. Диаграмма состояний (статусная модель)
16. Классы: откуда берутся
17. От модели к коду
18. Диаграмма компонентов
19. Диаграмма развёртывания
20. DFD: потоки данных
21. Какую диаграмму выбрать и как её проверить
22. Итоговый экзамен

### Типы заданий

`один ответ` · `несколько ответов` · `вписать ответ` · `сопоставление` · `порядок` ·
`конструктор схемы` (сборка диаграммы из палитры фигур с подсказками) ·
`песочница ERD` (выбор сущностей, кардинальностей и места внешнего ключа с живым кодом схемы)

## Запуск

Никакой сборки и зависимостей — одна самодостаточная HTML-страница.

```bash
# просто открыть
start index.html

# или локальным сервером
python -m http.server 8080
# → http://127.0.0.1:8080/
```

Прогресс сохраняется в `localStorage` браузера.

## Структура

```
index.html    готовая страница (открывать её)
trainer.html  исходник: фрагмент без doctype/head
build.js      сборка index.html из trainer.html
```

Правки вносятся в `trainer.html`, затем:

```bash
node build.js
```
